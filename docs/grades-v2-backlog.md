# Baholar jurnali — v2 backlog (qilinadigan ishlar)

> v1 kelishildi va amalga oshirildi (spec: [grades-v1-spec.md](./grades-v1-spec.md)).
> Quyidagilar **ataylab v1 doirasidan tashqarida qoldirilgan** — keyin qilinadi.

## 1. Topshiriq → toʻliq hujjat (Google Classroom uslubi)
v1 da topshiriq yengil: 4 maydon (Sarlavha, Toifa, Sana, Maksimal ball).
v2 da toʻliq hujjatga aylanadi:
- Yoʻriqnoma (Instructions) — matn muharriri.
- Ilovalar — Drive / YouTube / Upload / Link.
- Oʻquvchi topshiriqlari (Student Work): Assigned / Turned in / Graded tablar.
- Assign / Return jarayoni (kimga biriktirish, qaytarish).

## 2. Zavuch / kafedra governance qatlami
- "Loyiha / Maktab sozlamasi" yoqilganda: Toifa %, Shkala, Vazn sozlamalari maktab darajasiga koʻchadi.
- Oʻqituvchidagi tahrirlash tugmalari **disable** boʻladi (arxitektura v1 da tayyorlangan — data alohida qatlamda).
- Standartlar izchilligi (maintenance of standards).

## 3. "Custom" baholash shkalasi
- Oʻqituvchi oʻzi yorliq + chegara (cut-score) yasashi.
- Validlik xavfi sababli v1 da YOʻQ; faqat governance qatlami bilan birga kiritiladi (chegaralarni zavuch qulflaydi).

## 4. Statistik ishonchlilik (reliability) — chuqurroq
v1 da faqat oddiy signal bor (summativ N<3 → `!` + tooltip). v2 da:
- Kronbax-alfa / ichki ishonchlilik koeffitsiyenti.
- SEM (oʻlchashning standart xatosi) → "baho ehtimoli" / ishonch oraligʻi (±%).
- Toʻliq statistik ekvayting (item qiyinchilik koeffitsiyenti) — oson 80% ≠ qiyin 80%.

## 5. Comparative Judgement (qiyosiy baholash)
- Insho / ochiq ishlar uchun alohida interfeys (juftliklarni solishtirish metodikasi).
- Baholovchilar aro ishonchlilikni oshirish uchun.
